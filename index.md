# Wapn

### A Mi'kmaw Language Learning App

*"First light" in Mi'kmaw — the dawn of a new learning journey.*

---

**Wapn** is a mobile-first, gamified language learning app for Mi'kmaw (Mi'kmaq), modeled on Duolingo's proven learning mechanics. The app targets learners at all levels and serves the urgent need for Mi'kmaw language revitalization.

**Why this matters:** UNESCO classifies Mi'kmaw as "vulnerable." The percentage of children aged 0-4 learning Mi'kmaw dropped from 44% (1999) to 20% (2013). Without intervention, intergenerational transmission will collapse.

| **Offline-First** | Full functionality without internet |
| **Audio** | Native speaker recordings for every item |

| **Free Forever** | No ads, no paywalls, no monetization |
| **Orthography** | Francis-Smith (primary), Listuguj (toggle) |

## Mi'kmaw-Specific Features

- **Animacy Sort** — Unique exercise teaching animate/inanimate noun classification
- **Polysynthetic Approach** — Whole phrases first, then morpheme breakdown
- **Verb Class Training** — VAI, VII, VTA, VTI verb system
- **Custom Keyboard** — Barred-i (ɨ), long vowel marks, smart apostrophes
- **Waveform Comparison** — Honest pronunciation practice without unsupported speech-to-text

## Course Structure

**Course 1: Foundations** — Greetings, Family, Numbers, Animals, Food, Body, Colors, Seasons, Daily Routines, Places

**Course 2: Building Blocks** — Verb Basics, Animacy Deep Dive, Transitive Verbs, Questions, Tense, Home, Land & Water, Stories, Emotions
